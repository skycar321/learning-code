파이썬 피보나치 계산기의 간단한 아키텍처를 만들어드리겠습니다.

★ 인사이트 ─────────────────────────────────────
1. **메모이제이션(Memoization)**: 재귀 호출 결과를 캐싱하여 중복 계산 제거
2. **모듈 분리**: 계산 로직과 UI/IO 분리로 테스트 용이성 증대
3. **성능 비교**: 순환 vs 재귀 vs 메모이제이션 방식의 트레이드오프 이해
─────────────────────────────────────────────────

```python
# fibonacci_calculator.py
"""
피보나치 계산기 - 다양한 구현 방식 비교
"""

from typing import Dict, Callable


# ❌ BAD: 순환 없는 재귀 - O(2^n) 시간복잡도
def fibonacci_bad(n: int) -> int:
    """중복 계산이 많아 매우 비효율적"""
    if n <= 1:
        return n
    return fibonacci_bad(n - 1) + fibonacci_bad(n - 2)


# ✅ GOOD: 메모이제이션 - O(n) 시간복잡도
class FibonacciCalculator:
    """메모이제이션을 활용한 피보나치 계산기"""
    
    def __init__(self):
        self.memo: Dict[int, int] = {}
    
    def calculate(self, n: int) -> int:
        """재귀 + 메모이제이션으로 효율적 계산"""
        if n in self.memo:
            return self.memo[n]
        
        if n <= 1:
            result = n
        else:
            result = self.calculate(n - 1) + self.calculate(n - 2)
        
        self.memo[n] = result
        return result
    
    def reset(self) -> None:
        """메모 초기화"""
        self.memo.clear()


# ✅ GOOD: 반복문 - O(n) 시간복잡도, O(1) 공간
def fibonacci_iterative(n: int) -> int:
    """반복문으로 가장 효율적 구현"""
    if n <= 1:
        return n
    
    prev, curr = 0, 1
    for _ in range(2, n + 1):
        prev, curr = curr, prev + curr
    
    return curr


# 사용 예시
if __name__ == "__main__":
    calculator = FibonacciCalculator()
    
    print("=== 피보나치 계산 비교 ===")
    n = 30
    
    print(f"F({n}) = {calculator.calculate(n)}")
    print(f"F({n}) = {fibonacci_iterative(n)}")
    
    # 메모리 상태 확인
    print(f"캐시된 값 개수: {len(calculator.memo)}")
```

**아키텍처 다이어그램**:
```
입력 (n)
   ↓
[FibonacciCalculator]
   ├─ memo (캐시)
   └─ calculate() 메서드
   ↓
출력 (F(n))
```

**성능 비교**:
| 방식 | 시간복잡도 | 공간복잡도 | 추천도 |
|-----|----------|----------|-------|
| 순환 재귀 | O(2^n) | O(n) | ❌ |
| 메모이제이션 | O(n) | O(n) | ⭐⭐ |
| 반복문 | O(n) | O(1) | ⭐⭐⭐ |

이렇게 **메모이제이션**과 **반복문** 방식이 현업에서 실무에 사용되는 효율적인 패턴입니다! 🚀
