# AWS 학습 로드맵 (전문가용)

이 문서는 AWS (Amazon Web Services) 클라우드 인프라를 체계적으로 이해하고 실무에 적용하기 위한 학습 로드맵을 제공합니다.

---

## 학습 목표

AWS의 핵심 서비스를 활용하여 확장 가능하고, 가용성이 높으며, 안전하고 비용 효율적인 클라우드 네이티브 애플리케이션 아키텍처를 설계하고 구현하는 능력을 배양합니다.

---

## 학습 로드맵

| Step | 주제 | 설명 | 상태 |
|:----:|:-----|:-----|:------:|
| 1 | **핵심 컴퓨팅 및 인프라** | AWS 글로벌 인프라(Region/AZ)의 이해를 바탕으로, 가상 서버(EC2)와 Auto Scaling을 이용한 탄력적인 컴퓨팅 환경을 구축합니다. | 미완료 |
| 2 | **IAM과 계정 보안** | 최소 권한 원칙에 입각하여 IAM User, Group, Policy, Role을 사용한 체계적인 접근 제어 및 보안 모델을 수립합니다. | 미완료 |
| 3 | **VPC 기반의 네트워크 격리** | 논리적으로 격리된 가상 네트워크(VPC)를 설계하고, Public/Private 서브넷과 보안 그룹을 통해 다중 계층(Multi-tier) 아키텍처의 보안을 강화합니다. | 미완료 |
| 4 | **S3 객체 스토리지** | 무한한 확장성을 가진 S3를 활용하여 정적 데이터를 저장하고, 버저닝, 수명 주기 관리, 정적 웹 호스팅 등 고급 기능을 다룹니다. | 미완료 |
| 5 | **서버리스 컴퓨팅 (Lambda)** | 서버 관리 없이 코드를 실행하는 이벤트 기반 아키텍처를 이해하고, API Gateway와 Lambda를 연동하여 서버리스 API를 구축합니다. | 미완료 |

---

## 추가 학습 권장 사항

| 구분 | 주제 | 설명 |
|:----:|:-----|:-----|
| 중급 | **RDS와 관리형 데이터베이스** | 관계형 데이터베이스를 AWS에서 관리형 서비스로 운영하며 고가용성 및 백업/복구 전략을 학습합니다. |
| 중급 | **CloudWatch 모니터링** | 로그, 지표, 알림을 통합하여 인프라와 애플리케이션에 대한 가시성을 확보하고 이상 징후를 사전에 탐지합니다. |
| 고급 | **ECS/EKS와 컨테이너 오케스트레이션** | Docker 컨테이너를 클러스터 환경에서 효율적으로 배포, 관리, 확장하는 방법을 심화 학습합니다. |
| 고급 | **Infrastructure as Code (IaC)** | AWS CloudFormation 또는 Terraform을 사용하여 코드로 인프라를 정의하고, 버전 관리하며, 자동화된 방식으로 배포합니다. |
| 고급 | **CI/CD 파이프라인** | AWS Developer Tools(CodeCommit, CodeBuild, CodePipeline)를 연동하여 소스 코드 변경부터 배포까지의 과정을 자동화합니다. |
