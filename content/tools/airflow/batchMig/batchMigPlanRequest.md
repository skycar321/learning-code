## 배경

사용자가 사내망(완전 폐쇄망)에 Airflow를 도입하여 기존 배치들을 마이그레이션하려고 합니다.

## 현재 배치 구성 (순차 의존성 있음)

1. **스트림셋**: 크론탭 → 쉘 → curl로 스트림셋 API 호출 (타시스템 데이터 연동)
2. **파이썬배치**: 크론탭 → 쉘 → Python (스트림셋 데이터 1차 가공)
3. **스프링배치1**: 크론스케줄러 + DB 테이블 기반, chunk 프로세싱 (외부 API 호출)
4. **스프링배치2**: tasklet 구성 (UI용 데이터셋 구성)

## 환경 조건

- **네트워크**: 완전 폐쇄망 (인터넷 연결 불가, USB/내부저장소로 이미지 이동 필요)
- **서버 사양**: 16GB+ RAM (대규모)
- **실행 주기**: 배치마다 다름 (혼합)
- **의존성**: 스트림셋 → 파이썬배치 → 스프링배치1 → 스프링배치2 순차 실행

## 사용자 수준

- Airflow 미경험
- Docker 미경험
- 비전공자도 이해할 수 있는 상세한 설명 필요

## 요청사항

다음 내용을 포함한 상세한 도입 계획을 수립해주세요:

1. **사전 준비 단계**

- 폐쇄망을 위한 오프라인 설치 준비
- 필요한 Docker 이미지 목록과 다운로드 방법
- 필요한 Python 패키지 오프라인 설치 방법

2. **Docker 설치 및 기초**

- 폐쇄망 환경에서 Docker 설치 방법
- Docker 기본 개념과 명령어 설명

3. **Airflow 설치**

- docker-compose를 이용한 Airflow 설치
- 폐쇄망 환경에서의 이미지 로드 방법
- 초기 설정 및 웹 UI 접속

4. **DAG 설계**

- 4개 배치를 하나의 DAG 또는 여러 DAG로 구성하는 방법
- 순차 의존성 구현 방법
- 각 배치별 Operator 선택 (BashOperator, PythonOperator, HttpOperator 등)

5. **기존 배치 마이그레이션**

- 스트림셋 (curl API 호출) → Airflow Task 변환
- 파이썬배치 → Airflow Task 변환
- 스프링배치1,2 → Airflow에서 트리거하는 방법

6. **모니터링 및 운영**

- 웹 UI 사용법
- 실패 시 재시도 설정
- 알림 설정

7. **단계별 체크리스트**

- 각 단계 완료 확인 항목

각 단계를 비전공자도 이해할 수 있도록 상세하게 설명해주세요.
