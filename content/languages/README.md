# 언어별 학습 허브 (초보 → 실무 로드맵)

각 언어 폴더에는 단계별 실습 파일과 학습 계획(learning_plan)이 있습니다. 아래 순서대로 따라가면 **환경 준비 → 기본 문법 → 표준 라이브러리 → 실무 주제** 흐름을 밟을 수 있습니다.

## 추천 학습 경로
- **웹·프론트엔드**: JavaScript → TypeScript  
- **백엔드/범용**: Python 또는 Java → (선택) Go, Rust  
- **모바일/멀티플랫폼**: Kotlin

## 시작 전에
1) **에디터**: VS Code / IntelliJ / GoLand / PyCharm 등 자신이 익숙한 도구 설치  
2) **버전 관리자**: `asdf`, `sdkman`, `pyenv`, `nvm` 등 선택해 언어별 버전 충돌을 방지  
3) **필수 명령어 익히기**: `git status`, `git switch`, `git add -p`, `git stash`(Step4 Git에서 정리됨)

## 각 학습 계획이 포함하는 것
- 단계별 목표와 체크리스트
- 나쁜 예시 vs 좋은 예시(가능한 경우)
- 실습 파일 경로와 실행 방법
- 추가 심화 주제 제안

## 빠르게 훑기 (입문 로드맵)
- **1주차**: Python Step1~4 또는 JavaScript Step1~4 — 문법·함수·자료구조 기초
- **2주차**: TypeScript Step1~6 또는 Java Step1~6 — 타입·OOP·예외·모듈
- **3주차**: 선택 심화 — Concurrency(Go/Rust/Java Step8), Async(JS Step3, Kotlin Step4), 제네릭/Rust 라이프타임

필요한 언어를 골라 상단 링크를 눌러주세요. 학습 중 막히는 부분은 동일 Step 번호 파일을 열어 예제와 주석을 함께 보면 됩니다.
