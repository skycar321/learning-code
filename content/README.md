# 학습 리포지토리 안내 (content/)

초급자가 “무엇부터 시작할지” 바로 알 수 있도록 영역별 허브를 제공합니다. 모든 문서는 UTF-8 마크다운/예제 코드이며, 복사-실행 가능한 스니펫을 우선합니다.

## 빠른 길잡이
- **버전관리**: `tools/git_cli/git_cli_learning_plan.md` (Git 입문→실무)
- **언어 선택**: `languages/README.md` (언어별 로드맵 링크)
- **DB**: `databases/postgresql/postgresql_learning_plan.md`
- **DevOps**: `devops/docker/docker_learning_plan.md`, `devops/kubernetes/kubernetes_learning_plan.md`
- **프로세스**: `process/SoftwareDevelopmentLifecycle.md`

## 추천 학습 순서 (입문자)
1. Git CLI Step1~5 → 작업 관리 기초 다지기  
2. 언어 로드맵에서 한 언어 선택 (Python/JS/TS/Java 중 하나)  
3. Docker 로드맵 Step1~6 → 컨테이너 감 잡기  
4. 선택 심화: DB(Postgres) 또는 클라우드/쿠버네티스  

## 시각화
복잡한 흐름은 Mermaid 다이어그램으로 요약했습니다. GitHub/VS Code 등에서 바로 렌더링 가능합니다.
