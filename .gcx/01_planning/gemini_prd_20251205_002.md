# Product Requirements Document (PRD) v2.0
## Project: DevOps & Git CLI Cheatsheet Expansion
**Date**: 2025-12-05
**Author**: Gemini (Project Lead)

### 1. Overview
Following the successful deployment of basic CLI tools (`npm`, `cargo`, etc.), we identified a gap in "Quick Reference" materials for DevOps tools. While conceptual guides exist in `content/devops`, concise CLI cheatsheets are missing in `content/tools`.

### 2. Objectives
-   **Expand Toolset**: Add `docker`, `kubectl` (Kubernetes), and `git` (Cheatsheet version) to `content/tools/`.
-   **Standardization**: Apply the new "Step1_..._Cheatsheet.md" format with "Copy" button support.
-   **Usability**: Provide practical, copy-pasteable commands for daily workflows.

### 3. Scope
#### 3.1 New Content Modules
Target: `content/tools/`
1.  **Docker CLI** (`content/tools/docker/Step1_Docker_Cheatsheet.md`)
    -   Container lifecycle (run, stop, rm).
    -   Inspection (ps, logs, inspect).
    -   Cleanup (prune).
2.  **Kubernetes CLI** (`content/tools/kubectl/Step1_Kubectl_Cheatsheet.md`)
    -   Pod/Node diagnostics (get, describe, logs).
    -   Resource management (apply, delete, scale).
    -   Context switching (config).
3.  **Git CLI** (`content/tools/git/Step1_Git_Cheatsheet.md`)
    -   Essential workflow (init, add, commit, push, pull).
    -   Branching & Merging.
    -   Undo/Reset (checkout, reset, revert).
    -   *Note*: Distinct from existing `git_cli/*.sh` tutorials.

### 4. Success Metrics
-   3 new directories created in `content/tools/`.
-   Files strictly follow UTF-8 encoding.
-   Content verified by Claude (Accuracy) and Codex (Formatting).
