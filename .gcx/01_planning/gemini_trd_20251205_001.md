### 1. Architecture

#### 1.1 Content Structure & Navigation
The Rust server (`platform/src/main.rs`) uses `build_navigation` to recursively scan `../content`.
-   **Mechanism**: It detects subdirectories as Categories and Subcategories.
-   **Requirement**: New folders `content/tools/<tool_name>/` will be automatically recognized as:
    -   Category: `tools` (parent folder)
    -   Subcategory: `<tool_name>` (e.g., `npm`, `cargo`)
    -   Files: Markdown files within these folders.
-   **Action**: Create directory structure strictly using ASCII/English names.
    ```text
    content/
    |-- tools/
        |-- npm/
        |-- pip/
        |-- uv/
        |-- pipx/
        |-- homebrew/
        |-- cargo/
        |-- jq/
        |-- curl/
    ```

#### 1.2 UI Implementation (Copy Button)
-   **Target File**: `platform/templates/content.html`.
-   **Logic Refinement (Addressing Codex Feedback)**:
    -   **Target**: Do NOT copy `pre.innerText` directly (avoids copying button text). Target `pre code`.
    -   **Accessibility**: Add `aria-label="Copy code"` and keyboard focus support.
    -   **Error Handling**: `try-catch` block around `navigator.clipboard.writeText`. Show "Error" on failure (e.g., permission denied).
    -   **Positioning**: `pre` must be `relative`. Button `absolute top-2 right-2`.

### 2. Implementation Plan

#### Phase 1: Content Creation
-   Generate Markdown cheatsheets in `content/tools/`.
-   Ensure strictly UTF-8 encoding.

#### Phase 2: Frontend Logic
-   Inject JavaScript in `content.html`:
    ```javascript
    document.querySelectorAll('pre').forEach(pre => {
        // ... creation logic ...
        button.onclick = () => {
             // CRITICAL: Select code element only
            const codeText = pre.querySelector('code')?.innerText || pre.innerText; 
            navigator.clipboard.writeText(codeText).then(/*...*/).catch(/*...*/);
        };
    });
    ```

#### Phase 3: Verification Strategy
1.  **Sidebar Check**: Verify "tools" category appears in the left sidebar.
2.  **Copy Functionality**:
    -   Click "Copy" -> Paste into Notepad -> Verify NO button text ("Copy") is included.
    -   Verify "Copied!" feedback appears for 2 seconds.
3.  **Accessibility**: Tab key should focus the copy button.
