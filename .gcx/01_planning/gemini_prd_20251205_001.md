# Product Requirements Document (PRD)
## Project: Learning Platform Enhancement (CLI Tools & UI)
**Date**: 2025-12-05
**Author**: Gemini (Project Lead)

### 1. Project Overview
The goal is to expand the "Learning Code" platform's content to include essential developer CLI tools and enhance the user interface to support better code interaction.

### 2. Objectives
1.  **Content Expansion**: Add comprehensive references for frequently used terminal commands (`npm`, `npx`, `pip`, `uv`, `cargo`, `brew`, `pipx`) to the learning curriculum.
2.  **UI/UX Improvement**: Implement a "Copy to Clipboard" feature for code blocks to facilitate easy usage of commands.
3.  **Discovery**: Suggest and implement additional high-value tool documentation (e.g., `jq`, `curl`).

### 3. Scope
#### 3.1. New Content Modules (Priority: High)
Target Location: `content/tools/`
-   **Node.js Ecosystem**: `npm` (Package Manager), `npx` (Package Runner).
-   **Python Ecosystem**: `pip` (Standard PM), `uv` (Fast Python PM), `pipx` (Installable App Runner).
-   **Rust Ecosystem**: `cargo` (Integrate existing `docs/CARGO_COMMANDS.md` style).
-   **System/Package Management**: `brew` (Homebrew - macOS/Linux Package Manager).
-   **Utilities** (Proposed): `jq` (JSON Processor), `curl` (Network Request).

#### 3.2. UI Enhancements (Priority: Medium)
-   **Copy Code Button**:
    -   Add a floating "Copy" button to the top-right of every code block (`<pre><code>`).
    -   Visual feedback: Change icon/text to "Copied!" for 2 seconds after click.
    -   Style: Minimalist, distinct from code text, using Tailwind CSS.

### 4. Success Metrics
-   New modules appear correctly in the sidebar navigation.
-   "Copy" button works on all code blocks in the content view.
-   Documentation follows the consistent "Step-by-Step" or "Cheat Sheet" format.

### 5. Constraints
-   Must use existing `platform` (Rust/Axum) structure.
-   No new heavy CSS frameworks; use existing Tailwind setup.
-   Content must be compatible with the existing Markdown parser (`comrak` or similar used by the server).
